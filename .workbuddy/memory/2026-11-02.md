
## 渠道36 开放实际模型名（不再只能走 gpt-* 映射）
- 需求：用户想在别的 agent 里直接用 `deepseek-v4.1-flash` 等真实模型名，而不是只能填 gpt-6.1-sol。
- **关键坑**：只改 `channels.models` 不生效！New API 路由靠 **`abilities` 表**（group, model, channel_id, enabled, priority, weight），改完 models 后 /v1/models 不显示、调用报 `No available channel for model ... under group asxs`。
  正确做法：`channels.models` 与 `abilities` 两处都要写，然后重启 new-api 清缓存。
- 已验证可用的实际模型（上游 200）：deepseek-v4.1-flash、deepseek-v4.1-flash-sg、deepseek-v4-pro、glm-5.2、glm-5.3、glm-5.3-flash、minimax-m3.1-flash、kimi-k3.1-pro、hy4-preview、hy3。
- **上游无权限（已剔除）**：kimi-k3（model [Kimi-K3] service info not found）、kimi-k3.1-pro-highspeed、grok-4.7、gemini-3.8-flash（均 11158 类错误）。
- 渠道36 最终 18 个模型 × 2 组（asxs/c2a）= 36 条 abilities。入口模型 8 个（gpt-*）+ 实际模型 10 个。
- 计费核对：走入口 gpt-6.1-sol 与直接 actual name 都是 ratio 0.0685 / cache_ratio 0.02；直接调用时 logs.other.billing_model_name 为空（未发生映射），New API 回落到 origin model 计费，结果一致。
- 注意：token 18（GPT）有 model_limits 白名单只含 gpt-5.5，要用实际模型需先放开该令牌白名单。
- 待办：若后续再加模型，记得同时补 abilities，否则不生效。
