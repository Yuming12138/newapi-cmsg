## 新-api 管理 API 备忘补充

- 新增渠道：`POST /api/channel/`，body **必须**是 `{"mode":"single","channel":{...}}`。mode 只接受 `single` / `batch` / `multi_to_single`；直接传 channel 对象会报 `channel cannot be empty`，mode 空串会报 `不支持的添加模式`。
