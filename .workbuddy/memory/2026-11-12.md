
## cli2api 面板更新 EOF 修复 + 升级 v0.7.30 + mihomo 换新订阅
- 现象：面板 `docker pull ghcr.io/caigee-cmd/cli2api:v0.7.30 ... Head .../manifests/v0.7.30: EOF`，当前 v0.7.26。
- 根因：dockerd 全局 `HTTPS_PROXY=http://127.0.0.1:7897`，而 mihomo 老订阅(dasho.pqjc.site)未续费、节点全挂 → 代理 EOF。
  实测 `ghcr.io` 宿主直连 401(通)、走 7897 是 000；`api.github.com` 直连 200。
- **修复1（主线，已验证）**：`/etc/systemd/system/docker.service.d/http-proxy.conf` 的 NO_PROXY 加上
  `ghcr.io,.githubusercontent.com,pkg-containers.githubusercontent.com,github.com,api.github.com`，
  `systemctl daemon-reload && restart docker`（全容器中断 30-60s）。
  验证 `docker pull ...:v9.9.9` → `not found`（不再是 EOF）。
- **升级**：`docker pull ...:v0.7.30`（240MB）→ `sudo /opt/scripts/update-cli2api.sh v0.7.30`
  → `OK: now running v0.7.30 (healthy)` commit ff030bbeb5fea5c66f83fb52fbd8922dfe607041。
  真实请求 200 / 3.99s。面板清残留：`rm /var/lib/cli2api-updater/status.json && systemctl restart cli2api-updater`
  → current=v0.7.30, has_update=False, failed 状态消失。
- **修复2（用户要求换订阅）**：`/opt/mihomo/subscription.url` → `proxyinfo.net`（12 可用节点、98.34GB、到期 2026-12-10）。
  用脚本替换 config.yaml 的 proxies 段 + 6 个 proxy-groups 成员，保留 CMSG 的 DNS/rules/组名；mihomo -t 校验通过。
- 换完代理仍 000，日志 `hk1.jiedian.stream:8443 dns resolve failed: couldn't find ip`：
  新订阅节点 server 全是 `*.jiedian.stream` 域名，而生产 mihomo 的 fake-ip DNS 栈 + DoH nameserver 解不了机场域名
  （公共 DoH 全返回空；宿主 127.0.0.53 能解出 10/11 个）。`dns.enable` 改 true、加 `proxy-server-nameserver`、注入 `hosts:` 都无效。
  对照实验：同一订阅用「最小配置(无 dns 段)」在宿主跑 → 12 节点全 401(连通)，证明订阅本身没问题。
- **最终解法**：把 config.yaml 里所有节点 `server:` 域名直接替换成宿主解析出的**静态 IP**（10 个），
  剔除无 A 记录的 hk1 节点（并同步从组成员列表删除）。mihomo 不再需要解析节点域名 → 7897 恢复：
  api.github.com 403 / ghcr.io 401 / google.com 302，ttfb 0.5~1.2s。
- 备份：`/opt/mihomo/backups/config.yaml.bak-{subswap,dnsen,psn,hosts,staticip}-*` 与 `subscription.url.bak-subswap-*`；
  dockerd 代理备份 `/opt/new-api/backups/docker-http-proxy.conf.bak-*`。临时文件（含订阅地址）全清理。
- ⚠️ 遗留：`cmsg-asxs-channel45-balance.timer` 仍在跑，但渠道 45 已从 DB 消失，脚本每 5 分钟报 `channel 45 not found`；
  现在余额走 budget guard 的 /api/usage，这个 timer 可考虑停掉。
- ⚠️ 注意：config.yaml 里节点是静态 IP，若以后跑 `scripts/cmsg-update-mihomo-subscription.sh` 会覆盖回域名（且脚本按 dasho 节点名匹配，新订阅 0 命中会直接失败）。
