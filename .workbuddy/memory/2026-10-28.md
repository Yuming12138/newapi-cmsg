
## 额度申请功能变灰（可申请 $0）修复
- 现象：用户面板「额度申请」显示"可申请增加 $0"、"当前无法申请额度"，按钮不可点。
- 根因：`user_quota_guard_setting.restricted_balance_cap_usd` = 25 与 `daytime_base_usd` = 25 相等。
  service/user_quota_request.go:237-243 计算 `requestAmountUSD = min(20, max(0, cap - target))`，
  而 target = min(base + extra, cap) = 25，故 cap - target 恒为 0 → 走 `requestAmountQuota == 0` 分支，
  reason = "daily quota cap of $25 has been reached"。
- 修复：cap 25 → **65**（base 25 + 两次申请各 20）。重启后 DB 值保持 65，无代码回写（只有测试赋值）。
- 生效后计算：target=min(25,65)=25 → 首次可申请 min(20, 65-25)=$20；extra=20 后 target=45 → 第二次仍可 20；两次后 target=65，配合每日 2 次上限收敛。
- 该参数无历史审计，无法确定何时被改成 25/25，推测为后台手工调整。
- 相关参数：user_quota_request 阈值 $10、单次 $20、每日 2 次（常量在 service/user_quota_request.go:25-27）。
- 面板数据来自 GET /api/user/self 的 profile.quota_request 字段（controller/user.go:493）。
